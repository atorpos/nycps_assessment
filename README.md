# NYCPS OSP – Web Developer Coding Assessment

This repository contains my solutions to a web development coding assessment for the **Office of School Performance (OSP), New York City Public Schools**.

The assessment covers JavaScript, SQL, data visualization, and dynamic web applications.

## Assessment Overview

1. **JavaScript Array Filtering** – Filter and return names based on age.
2. **Set Validation** – Determine whether three cards form a valid Set.
3. **Number Reversal** – Reverse an integer without converting it to a string.
4. **SQL LEFT JOIN** – Retrieve students and their assigned advisors.
5. **Data Visualization** – Build interactive credit accumulation charts using Chart.js, including an approach for API integration.

## Technologies

- HTML5, CSS3, JavaScript
- SQL (PostgreSQL)
- Chart.js
- Node.js / Express (backend example)

## View the Assessment

Open [`tests/results.html`](tests/results.html) in a browser to view the solutions and interactive examples.

## Notes

The assessment uses sample data for demonstration. Chart.js is loaded through a CDN, so an internet connection is required for the charts.

The dynamic visualization section includes a frontend demonstration and a proposed backend implementation.
